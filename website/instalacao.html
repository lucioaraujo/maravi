Instalar o Maravi

O Maravi 0.1.1 sai como pacote para Linux x86_64. Roda no seu computador: um pequeno servidor local em 127.0.0.1 e o navegador como interface. Nada é enviado pela rede.

Requisitos: Linux x86_64 com glibc 2.35 ou mais nova (Ubuntu 22.04+, Linux Mint 21+, Debian 12+, Fedora, Arch, openSUSE Tumbleweed); um navegador; cerca de 1 GB livre em disco (o pacote aberto ocupa ~350 MB); o FFmpeg (obrigatório, para ler os arquivos de áudio). Só para ler partituras impressas, opcionais: Audiveris, MuseScore, Poppler e ImageMagick. Windows e macOS não têm suporte nesta versão.

Passo a passo:

  1. Instale o FFmpeg: Ubuntu, Mint, Debian: sudo apt install ffmpeg; Fedora: ative o RPM Fusion e sudo dnf install ffmpeg; Arch: sudo pacman -S ffmpeg.
  2. Baixe maravi-0.1.1-linux-x86_64.tar.xz em Releases. Para conferir o download: sha256sum -c maravi-0.1.1-linux-x86_64.tar.xz.sha256
  3. Descompacte onde guarda seus programas, por exemplo na pasta pessoal: tar -xf maravi-0.1.1-linux-x86_64.tar.xz
  4. Abra: ./maravi-0.1.1-linux-x86_64/maravi. O navegador abre em http://127.0.0.1:5001/; se não abrir, digite esse endereço.
  5. Para fechar, Ctrl+C no terminal (ou feche o terminal).

Se a porta 5001 estiver ocupada: MARAVI_PORT=5052 ./maravi-0.1.1-linux-x86_64/maravi

Partituras impressas (opcional). A página "PDF / imagem" precisa de mais quatro programas; sem eles, o áudio funciona e a página diz o que falta. Ubuntu, Mint, Debian: sudo apt install poppler-utils imagemagick musescore3 (ou o MuseScore 4 de musescore.org). O Audiveris vem das releases do Audiveris (no Ubuntu, o .deb); o Maravi acha /opt/audiveris/bin/Audiveris sozinho, e para outro lugar use MARAVI_AUDIVERIS_BIN=/caminho/do/Audiveris. Para o MuseScore fora do PATH, MARAVI_MUSESCORE_BIN.

Seus arquivos. Cada trabalho fica numa pasta temporária (/tmp/maravi_webapp_jobs/), mostrada na página do resultado, que o sistema pode limpar ao reiniciar. Guarde ou baixe o MusicXML e o MIDI antes de fechar. O arquivo que você escolheu nunca é alterado.

Desinstalar: apague a pasta maravi-0.1.1-linux-x86_64. A partir do código (desenvolvedores, Python 3.12): veja From source.
