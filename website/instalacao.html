Instalar o Maravi

O Maravi 0.1.2 oferece três formatos para Linux x86_64. Roda no seu computador: um pequeno servidor local em 127.0.0.1 e o navegador como interface. Nada é enviado pela rede.

Requisitos: Linux x86_64 com glibc 2.35 ou mais nova (Ubuntu 22.04+, Linux Mint 21+, Debian 12+, Fedora, Arch, openSUSE Tumbleweed); um navegador; cerca de 1 GB livre em disco (o pacote aberto ocupa ~400 MB); o FFmpeg (obrigatório, para ler os arquivos de áudio). Só para ler partituras impressas, opcionais: Audiveris, MuseScore, Poppler e ImageMagick. Windows e macOS não têm suporte nesta versão.

Passo a passo:

  1. Abra a versão 0.1.2 do Maravi no GitHub. Se baixar os três pacotes, salve SHA256SUMS na mesma pasta e rode sha256sum -c SHA256SUMS. Para um único download, compare o resultado do sha256sum com a linha correspondente.
  2. Escolha um formato:
    • Debian, Ubuntu e Mint (.deb): na pasta de downloads, rode sudo apt install ./maravi-0.1.2-linux-x86_64.deb. O pacote instala o FFmpeg e adiciona o Maravi ao menu. Também dá para rodar maravi no terminal.
    • AppImage: instale o FFmpeg da sua distribuição. Rode chmod +x maravi-0.1.2-linux-x86_64.AppImage e ./maravi-0.1.2-linux-x86_64.AppImage. Se o FUSE não estiver disponível, acrescente --appimage-extract-and-run ao comando.
    • Instalação para seu usuário (.tar.gz): instale o FFmpeg e o Python 3. Extraia maravi-0.1.2-linux-x86_64.tar.gz, entre na pasta extraída e rode ./install.sh. Abra pelo menu ou rode ~/.local/bin/maravi.
  3. O navegador abre em http://127.0.0.1:5001/. Se não abrir, digite o endereço. Para fechar o Maravi, pressione Ctrl+C ou feche o terminal dele.

No AppImage ou .tar.gz, instale o FFmpeg com sudo apt install ffmpeg no Debian, Ubuntu e Mint, sudo dnf install ffmpeg com o RPM Fusion no Fedora ou sudo pacman -S ffmpeg no Arch. Se a porta 5001 estiver ocupada, coloque MARAVI_PORT=5052 antes do comando que abre o programa.

Partituras impressas (opcional). A página "PDF / imagem" precisa de mais quatro programas; sem eles, o áudio funciona e a página diz o que falta. Ubuntu, Mint, Debian: sudo apt install poppler-utils imagemagick musescore3 (ou o MuseScore 4 de musescore.org). O Audiveris vem das releases do Audiveris (no Ubuntu, o .deb); o Maravi acha /opt/audiveris/bin/Audiveris sozinho, e para outro lugar use MARAVI_AUDIVERIS_BIN=/caminho/do/Audiveris. Para o MuseScore fora do PATH, MARAVI_MUSESCORE_BIN.

Seus arquivos. Cada trabalho fica numa pasta temporária (/tmp/maravi_webapp_jobs/), mostrada na página do resultado, que o sistema pode limpar ao reiniciar. Guarde ou baixe o MusicXML e o MIDI antes de fechar. O arquivo que você escolheu nunca é alterado.

Desinstalar: no Debian, rode sudo apt remove maravi. Para o AppImage, apague o arquivo. Na instalação para seu usuário, rode ./install.sh --remove na pasta extraída. A partir do código (desenvolvedores, Python 3.12): veja From source.
