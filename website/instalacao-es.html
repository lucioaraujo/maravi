Instalar Maravi

Maravi 0.1.1 se distribuye como paquete para Linux x86_64. Funciona en su computadora: un pequeño servidor local en 127.0.0.1 y el navegador como interfaz. Nada se envía por la red.

Requisitos: Linux x86_64 con glibc 2.35 o más reciente (Ubuntu 22.04+, Linux Mint 21+, Debian 12+, Fedora, Arch, openSUSE Tumbleweed); un navegador; cerca de 1 GB libre en disco (el paquete descomprimido ocupa ~400 MB); FFmpeg (obligatorio, para leer los archivos de audio). Solo para leer partituras impresas, opcionales: Audiveris, MuseScore, Poppler e ImageMagick. Windows y macOS no tienen soporte en esta versión.

Paso a paso:

  1. Instale FFmpeg: Ubuntu, Mint, Debian: sudo apt install ffmpeg; Fedora: active RPM Fusion y sudo dnf install ffmpeg; Arch: sudo pacman -S ffmpeg.
  2. Descargue maravi-0.1.1-linux-x86_64.tar.xz en Releases. Para verificar: sha256sum -c maravi-0.1.1-linux-x86_64.tar.xz.sha256
  3. Descomprima, por ejemplo en su carpeta personal: tar -xf maravi-0.1.1-linux-x86_64.tar.xz
  4. Abra: ./maravi-0.1.1-linux-x86_64/maravi. El navegador se abre en http://127.0.0.1:5001/; si no, escriba esa dirección.
  5. Para cerrarlo, Ctrl+C en la terminal (o cierre la terminal).

Si el puerto 5001 está ocupado: MARAVI_PORT=5052 ./maravi-0.1.1-linux-x86_64/maravi

Partituras impresas (opcional). La página «PDF / imagen» necesita cuatro programas más; sin ellos, el audio funciona y la página indica lo que falta. Ubuntu, Mint, Debian: sudo apt install poppler-utils imagemagick musescore3 (o MuseScore 4 de musescore.org). Audiveris se descarga en las releases de Audiveris (el .deb en Ubuntu); Maravi encuentra /opt/audiveris/bin/Audiveris solo, y para otra ubicación use MARAVI_AUDIVERIS_BIN=/ruta/a/Audiveris. Para MuseScore fuera del PATH, MARAVI_MUSESCORE_BIN.

Sus archivos. Cada trabajo queda en una carpeta temporal (/tmp/maravi_webapp_jobs/), indicada en la página del resultado, que el sistema puede vaciar al reiniciar. Guarde o descargue el MusicXML y el MIDI antes de cerrar. El archivo que usted eligió nunca se modifica.

Desinstalar: borre la carpeta maravi-0.1.1-linux-x86_64. Desde el código fuente (desarrolladores, Python 3.12): vea From source.
