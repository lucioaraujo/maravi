Installer Maravi

Maravi 0.1.2 propose trois formats pour Linux x86_64. Il fonctionne sur votre ordinateur : un petit serveur local sur 127.0.0.1 et le navigateur comme interface. Rien n'est envoyé sur le réseau.

Configuration requise : Linux x86_64 avec glibc 2.35 ou plus récente (Ubuntu 22.04+, Linux Mint 21+, Debian 12+, Fedora, Arch, openSUSE Tumbleweed) ; un navigateur ; environ 1 Go libre (le paquet décompressé occupe ~400 Mo) ; FFmpeg (obligatoire, pour lire les fichiers audio). Seulement pour lire des partitions imprimées, facultatifs : Audiveris, MuseScore, Poppler et ImageMagick. Windows et macOS ne sont pas pris en charge dans cette version.

Pas à pas :

  1. Ouvrez la version 0.1.2 de Maravi sur GitHub. Si vous téléchargez les trois paquets, placez SHA256SUMS dans le même dossier et lancez sha256sum -c SHA256SUMS. Pour un seul fichier, comparez le résultat de sha256sum avec la ligne correspondante.
  2. Choisissez un format :
    • Debian, Ubuntu et Mint (.deb) : dans le dossier de téléchargement, lancez sudo apt install ./maravi-0.1.2-linux-x86_64.deb. Le paquet installe FFmpeg et ajoute Maravi au menu. Vous pouvez aussi lancer maravi dans un terminal.
    • AppImage : installez FFmpeg pour votre distribution. Exécutez chmod +x maravi-0.1.2-linux-x86_64.AppImage, puis ./maravi-0.1.2-linux-x86_64.AppImage. Si FUSE est indisponible, ajoutez --appimage-extract-and-run à la commande.
    • Installation pour votre compte (.tar.gz) : installez FFmpeg et Python 3. Extrayez maravi-0.1.2-linux-x86_64.tar.gz, ouvrez le dossier extrait et lancez ./install.sh. Ouvrez Maravi depuis le menu ou lancez ~/.local/bin/maravi.
  3. Le navigateur s’ouvre à http://127.0.0.1:5001/. Sinon, saisissez cette adresse. Pour arrêter Maravi, appuyez sur Ctrl+C ou fermez son terminal.

Pour l’AppImage ou le .tar.gz, installez FFmpeg avec sudo apt install ffmpeg sur Debian, Ubuntu et Mint, sudo dnf install ffmpeg avec RPM Fusion sur Fedora, ou sudo pacman -S ffmpeg sur Arch. Si le port 5001 est occupé, placez MARAVI_PORT=5052 avant la commande de lancement.

Partitions imprimées (facultatif). La page « PDF / image » demande quatre programmes de plus ; sans eux, l'audio fonctionne et la page indique ce qui manque. Ubuntu, Mint, Debian : sudo apt install poppler-utils imagemagick musescore3 (ou MuseScore 4 sur musescore.org). Audiveris se télécharge dans les releases d'Audiveris (le .deb sous Ubuntu) ; Maravi trouve /opt/audiveris/bin/Audiveris tout seul, sinon utilisez MARAVI_AUDIVERIS_BIN=/chemin/vers/Audiveris. Pour MuseScore hors du PATH, MARAVI_MUSESCORE_BIN.

Vos fichiers. Chaque travail vit dans un dossier temporaire (/tmp/maravi_webapp_jobs/), indiqué sur la page du résultat, que le système peut vider au redémarrage. Enregistrez ou téléchargez le MusicXML et le MIDI avant de fermer. Le fichier choisi n'est jamais modifié.

Désinstaller : pour le paquet Debian, lancez sudo apt remove maravi. Pour l’AppImage, supprimez le fichier. Pour l’installation utilisateur, lancez ./install.sh --remove depuis le dossier extrait. Depuis le code source (développeurs, Python 3.12) : voir From source.
