Installer Maravi

Maravi 0.1.1 est distribué en paquet pour Linux x86_64. Il fonctionne sur votre ordinateur : un petit serveur local sur 127.0.0.1 et le navigateur comme interface. Rien n'est envoyé sur le réseau.

Configuration requise : Linux x86_64 avec glibc 2.35 ou plus récente (Ubuntu 22.04+, Linux Mint 21+, Debian 12+, Fedora, Arch, openSUSE Tumbleweed) ; un navigateur ; environ 1 Go libre (le paquet décompressé occupe ~400 Mo) ; FFmpeg (obligatoire, pour lire les fichiers audio). Seulement pour lire des partitions imprimées, facultatifs : Audiveris, MuseScore, Poppler et ImageMagick. Windows et macOS ne sont pas pris en charge dans cette version.

Pas à pas :

  1. Installez FFmpeg : Ubuntu, Mint, Debian : sudo apt install ffmpeg ; Fedora : activez RPM Fusion puis sudo dnf install ffmpeg ; Arch : sudo pacman -S ffmpeg.
  2. Téléchargez maravi-0.1.1-linux-x86_64.tar.xz dans Releases. Pour vérifier : sha256sum -c maravi-0.1.1-linux-x86_64.tar.xz.sha256
  3. Décompressez-le, par exemple dans votre dossier personnel : tar -xf maravi-0.1.1-linux-x86_64.tar.xz
  4. Lancez : ./maravi-0.1.1-linux-x86_64/maravi. Le navigateur s'ouvre sur http://127.0.0.1:5001/ ; sinon, saisissez cette adresse.
  5. Pour l'arrêter, Ctrl+C dans le terminal (ou fermez-le).

Si le port 5001 est occupé : MARAVI_PORT=5052 ./maravi-0.1.1-linux-x86_64/maravi

Partitions imprimées (facultatif). La page « PDF / image » demande quatre programmes de plus ; sans eux, l'audio fonctionne et la page indique ce qui manque. Ubuntu, Mint, Debian : sudo apt install poppler-utils imagemagick musescore3 (ou MuseScore 4 sur musescore.org). Audiveris se télécharge dans les releases d'Audiveris (le .deb sous Ubuntu) ; Maravi trouve /opt/audiveris/bin/Audiveris tout seul, sinon utilisez MARAVI_AUDIVERIS_BIN=/chemin/vers/Audiveris. Pour MuseScore hors du PATH, MARAVI_MUSESCORE_BIN.

Vos fichiers. Chaque travail vit dans un dossier temporaire (/tmp/maravi_webapp_jobs/), indiqué sur la page du résultat, que le système peut vider au redémarrage. Enregistrez ou téléchargez le MusicXML et le MIDI avant de fermer. Le fichier choisi n'est jamais modifié.

Désinstaller : supprimez le dossier maravi-0.1.1-linux-x86_64. Depuis le code source (développeurs, Python 3.12) : voir From source.
