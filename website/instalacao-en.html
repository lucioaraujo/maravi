Installing Maravi

Maravi 0.1.1 ships as a package for Linux x86_64. It runs on your computer: a small local server on 127.0.0.1 and your browser as the interface. Nothing is sent over the network.

Requirements

  • Linux x86_64 with glibc 2.35 or newer: Ubuntu 22.04 or newer, Linux Mint

21 or newer, Debian 12 or newer, Fedora, Arch, openSUSE Tumbleweed.

  • A web browser (Firefox, Chromium, Chrome).
  • About 1 GB free on disk (the unpacked package takes ~350 MB).
  • FFmpeg (required: Maravi uses it to read audio files).
  • Only to read printed scores (PDF or image), optionally: Audiveris,

MuseScore, Poppler and ImageMagick.

Windows and macOS are not supported in this version.

Step by step

  1. Install FFmpeg:
    • Ubuntu, Mint, Debian: sudo apt install ffmpeg
    • Fedora: enable RPM Fusion, then sudo dnf install ffmpeg
    • Arch: sudo pacman -S ffmpeg
  2. Download maravi-0.1.1-linux-x86_64.tar.xz from Releases. To check the download, compare it with the .sha256 file: sha256sum -c maravi-0.1.1-linux-x86_64.tar.xz.sha256
  3. Unpack it where you keep your programs, for example your home folder: tar -xf maravi-0.1.1-linux-x86_64.tar.xz
  4. Start it: ./maravi-0.1.1-linux-x86_64/maravi The browser opens at http://127.0.0.1:5001/. If it does not, open that address yourself.
  5. To stop Maravi, press Ctrl+C in the terminal (or close it).

If port 5001 is busy, choose another one: MARAVI_PORT=5052 ./maravi-0.1.1-linux-x86_64/maravi

Reading printed scores (optional)

The "PDF / image" page needs four more programs. Without them Maravi still works for audio, and the page says what is missing.

  • Ubuntu, Mint, Debian: sudo apt install poppler-utils imagemagick musescore3

(or MuseScore 4 from musescore.org)

  • Audiveris: download the package for your system from

Audiveris releases (for Ubuntu, the .deb). Maravi finds /opt/audiveris/bin/Audiveris by itself; for another place, start Maravi with MARAVI_AUDIVERIS_BIN=/path/to/Audiveris.

  • If MuseScore is not on your PATH, use MARAVI_MUSESCORE_BIN.

Your files

Each job lives in a temporary folder (/tmp/maravi_webapp_jobs/), shown on the result page. The system may clear it on restart. Save or download your MusicXML and MIDI before closing. Maravi never changes the file you chose.

Uninstall

Delete the maravi-0.1.1-linux-x86_64 folder. Maravi writes nothing else outside the temporary folder.

From source

For developers, on any system with Python 3.12 (tested only on Linux):

git clone https://github.com/lucioaraujo/maravi.git && cd maravi
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements-local-linux-py312.txt
.venv/bin/python -m pip install --no-deps basic-pitch==0.4.0
.venv/bin/python -m unittest discover -s tests -p 'test_*.py'
.venv/bin/python run_maravi.py

Technical notes (dependencies, the package recipe, smoke tests): [INSTALL_LOCAL.md](INSTALL_LOCAL.md), in Portuguese.
